- 年度数が増える（R5年度が追加され、全5年分のデータになる）ほど、この「年度ごとの一律のズレ」がモデルの残差（予測誤差）として現れるため、決定係数（$R^2$）が低下します。

### 原因②：インセンティブ分の非線形性（順位制）による構造的な歪み

「インセンティブ分」は、5つの指標の数値そのものではなく、**47都道府県ごとの順位（ランク）**によって階段状に決定されます。

- 線形モデル（重回帰分析）では、この非線形な「順位付けによる±0.01%〜0.16%程度の加減算」を指標値から直接完璧にフィッティングすることができません。
- R5年度が補充されることで、さらに年度間の順位の変動やインセンティブ基準のズレが加わり、線形フィッティングの誤差が大きくなり決定係数が低下しました。

NOTE

**XGBoostアンサンブル（統合モデル）の強み** 重回帰分析単体ではR5年度補充後に決定係数が $0.9171$ まで低下しましたが、アンサンブルモデル（重回帰＋残差XGBoost）では **$0.9626$** と非常に高い精度を維持しています。これは、XGBoostが決定木によって「年度ごとの共通料率のズレ」や「インセンティブの非線形なランク効果」を残差から精度高く予測・補正できているためです。
