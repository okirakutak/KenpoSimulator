R² 回帰分析後、実データとの乖離度を調べるにはどうしたら良いでしょうか？

回帰分析後に「実データとの乖離（＝どれだけズレているか）」を評価する方法はいくつかあります。目的に応じて使い分けるのがポイントです。

---

## ① 残差（residual）を見る

まず基本はこれです。

- **残差 = 実測値 − 予測値**
- 各データごとにどれだけズレたかが分かる

### チェックポイント

- 残差がランダムにばらついているか
- 特定のパターン（曲線・偏り）がないか  
    → パターンがあると「モデルが合っていない」可能性あり

---

## ② 全体のズレを数値で評価（誤差指標）

よく使う代表的な指標です：

### ■ MAE（平均絶対誤差）

- ズレの平均（絶対値）
- 直感的で分かりやすい

MAE=1n∑∣y−y^∣MAE = \frac{1}{n} \sum |y - \hat{y}|MAE=n1​∑∣y−y^​∣

👉 「平均してどれくらいズレているか」

---

### ■ RMSE（二乗平均平方根誤差）

- 大きなズレを強く評価

RMSE=1n∑(y−y^)2RMSE = \sqrt{\frac{1}{n} \sum (y - \hat{y})^2}RMSE=n1​∑(y−y^​)2​

👉 外れ値の影響を重視したいとき

---

### ■ MAPE（平均絶対パーセント誤差）

- 割合でズレを見る

MAPE=100n∑∣y−y^y∣MAPE = \frac{100}{n} \sum \left| \frac{y - \hat{y}}{y} \right|MAPE=n100​∑​yy−y^​​​

👉 「何％ズレているか」を知りたいとき

---

## ③ 決定係数（R²）

- モデルの説明力を評価

R2=1−残差のばらつきデータ全体のばらつきR^2 = 1 - \frac{\text{残差のばらつき}}{\text{データ全体のばらつき}}R2=1−データ全体のばらつき残差のばらつき​

👉 1に近いほど良い  
👉 ただし「ズレの大きさ」そのものではない点に注意

データ分析の手法は色々あると思いますが、回帰分析以外でも提案された方法で乖離度を調べるのでしょうか？

結論から言うと、**はい。回帰分析以外の多くのデータ分析手法でも「予測値と実測値の乖離」を同様の考え方で評価します。**  
ただし、**手法の種類によって使う指標や見方が変わる**のが重要なポイントです。

# 🔎 まず大枠の考え方

乖離の評価は基本的に次の3タイプに分かれます：

### ① 数値予測（回帰・時系列など）

👉 誤差（残差）で評価  
→ あなたが見ている方法（MAE・RMSEなど）

---

### ② 分類（カテゴリを当てる）

👉 正解・不正解で評価  
→「ズレ」ではなく「当たり外れ」

---

### ③ 異常検知・クラスタリング

👉 「どれだけ外れているか」を距離や確率で評価

---

# 📊 手法別の違い

## ① 回帰・時系列予測（同じ考え方）

例：

- 線形回帰
- ランダムフォレスト回帰
- ニューラルネット
- ARIMA など

👉 **全部同じでOK**

- MAE / RMSE / MAPE
- 残差プロット

つまり  
👉 モデルが違っても「予測 vs 実測」で比較

---

## ② 分類モデル（考え方が変わる）

例：

- ロジスティック回帰
- 決定木
- SVM
- ニューラルネット

👉 乖離の見方はこうなる：

- 正解率（Accuracy）
- 適合率（Precision）
- 再現率（Recall）
- F1スコア

さらに：

- **確率出力がある場合**  
    → 「予測確率 − 実際」のズレも見れる  
    （例：予測0.9なのに外れ → 大きな乖離）

---

## ③ クラスタリング（教師なし学習）

例：

- k-means
- 階層クラスタリング

👉 「乖離」はこう見る：

- クラスタ中心からの距離
- シルエット係数

👉 意味：

- 「このデータはどれだけ“所属グループから外れているか”」

---

## ④ 異常検知

例：

- Isolation Forest
- LOF

👉 乖離の考え方：

- 異常スコア
- 距離・密度の低さ

👉 要するに：

- 「普通からどれだけズレているか」

---

## ⑤ 次元削減（PCAなど）

👉 少し特殊

- 再構成誤差（reconstruction error）

👉 意味：

- 元のデータに戻したときのズレ

---

# 💡 まとめ（超重要）

乖離の見方はこう整理できます：

|手法|乖離の見方|
|---|---|
|回帰・時系列|実測 − 予測（誤差）|
|分類|正解／不正解・確率のズレ|
|クラスタリング|中心からの距離|
|異常検知|異常スコア|
|次元削減|再構成誤差|

---

# 🎯 実務的な理解

本質は共通です：

👉 **「モデルが想定した値」と「実際（または構造）」のズレ**

ただし

- 数値 → 差分
- カテゴリ → 正誤
- 構造 → 距離

と**表現が変わるだけ**です。

# ① 残差の計算（GAS）

```
function calcResiduals() {  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();  const data = sheet.getRange("A2:B").getValues();  const residuals = data.map(row => {    const actual = row[0];    const predicted = row[1];    if (actual === "" || predicted === "") return [""];    return [actual - predicted];  });  sheet.getRange(2, 3, residuals.length, 1).setValues(residuals);}
```

👉 C列に「実測 − 予測」が入ります

---

# ② RMSE / MAE の計算

```
function calcErrorMetrics() {  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();  const data = sheet.getRange("A2:B").getValues();  let sumAbs = 0;  let sumSq = 0;  let count = 0;  data.forEach(row => {    const actual = row[0];    const predicted = row[1];    if (actual === "" || predicted === "") return;    const error = actual - predicted;    sumAbs += Math.abs(error);    sumSq += error * error;    count++;  });  const mae = sumAbs / count;  const rmse = Math.sqrt(sumSq / count);  sheet.getRange("E2").setValue("MAE");  sheet.getRange("F2").setValue(mae);  sheet.getRange("E3").setValue("RMSE");  sheet.getRange("F3").setValue(rmse);}
```

👉 シート上に数値が出ます

```
function createScatterPlot() {  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();  const chart = sheet.newChart()    .setChartType(Charts.ChartType.SCATTER)    .addRange(sheet.getRange("A2:B"))    .setPosition(2, 8, 0, 0)    .setOption("title", "Actual vs Predicted")    .setOption("hAxis", { title: "Actual" })    .setOption("vAxis", { title: "Predicted" })    .build();  sheet.insertChart(chart);}
```

👉 対角線に近いほど良い

## ■ 残差プロット

```
function createResidualPlot() {  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();  const chart = sheet.newChart()    .setChartType(Charts.ChartType.SCATTER)    .addRange(sheet.getRange("B2:C")) // 予測 vs 残差    .setPosition(20, 8, 0, 0)    .setOption("title", "Residual Plot")    .setOption("hAxis", { title: "Predicted" })    .setOption("vAxis", { title: "Residual" })    .build();  sheet.insertChart(chart);}
```
