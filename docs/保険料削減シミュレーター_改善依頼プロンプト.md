# 保険料削減シミュレーター 改善依頼プロンプト

## 対象
協会けんぽ 保険料削減シミュレーター（Webアプリ）

## 目的
ホワイトボードでのレビューフィードバックをもとに、UI/UX・機能面の改善を行う。以下の依頼事項に沿って実装・修正してください。

---

## A. 概要・説明の追加
- [ ] シミュレーターの概要説明を追加する。「正確な数値ではない（あくまで目安である）」旨を明記する。（加藤空武）
- [ ] 給与明細のどの項目を見て入力すればよいか、説明を追加する。（加藤空武）
- [ ] マイナポータルと年金情報を連携すると、自分の保険料が自動的にわかる機能の検討。（Yo Ta）

## B. 入力フォーム
- [ ] タイトルと入力欄を2段構成のレイアウトに変更する。
- [ ] 保険料ではなく「年収」を入力する形式にした方がわかりやすい可能性がある。（辻本航）
- [ ] 個人モードと会社モードを分けられないか検討する。
- [ ] 会社モード用の入力項目を追加する：（Yo Ta）
  - 会社が支払った保険料の領収書に記載されている健康保険料額・介護保険料額
  - 協会けんぽへ加入している社員数
  - 40歳以上の社員数

## C. 結果表示
- [ ] 「シミュレーション結果」をメイン表示にし、金額など重要な数値を目立たせて印象を強める。（辻本航）
- [ ] 上下で似た情報が重複表示されているブロックをまとめる。（辻本航）
- [ ] 不要なブロック（グラフ等）がないか精査し、削除を検討する。（Takayuki Naoe）
- [ ] 浮いた金額で何ができるかを例示し、イメージしやすくする（例：「映画1本見られます！」など）。（加藤空武）
- [ ] 傷病手当金の受給額の平均（長崎県）を表示することを検討する。（Yo Ta）
- [ ] 余白が空きすぎている箇所のレイアウトを調整する。

## D. ビジュアル・デザイン
- [ ] 全体的に暗い配色を、明るい色調に変更する。（加藤空武／Takayuki Naoe）
- [ ] 文字サイズが小さいため、拡大を検討する。
- [ ] 内容がわかりづらいという指摘あり。日本地図などのビジュアル要素の追加を検討する。（加藤空武）

## E. フッター
- [ ] コピーライト表記（© 長大データバンクデータ塾「長崎県民の手取りを増やす」All Rights Reserved.）を一番下に配置する。（加藤空武）
